# Onças Prod — versão de trabalho

## Abrir a prévia local

No terminal, dentro desta pasta, execute:

```bash
npm run dev
```

O terminal mostra o endereço local, normalmente `http://127.0.0.1:5173/`. Abra esse endereço no navegador. Se a porta já estiver ocupada, o servidor escolhe a próxima disponível e informa o link. Mantenha o terminal aberto enquanto estiver usando a prévia; para encerrar, pressione `Ctrl+C`.

Também é possível abrir `index.html` com a extensão Live Server do VS Code.

A hero combina os textos de criação, inclusão e colaboração com artes visuais, música e moda. A estampa `assets/Estampa de Leopardo Rosa Neon e Preta.png` aparece na área de trabalho conforme o CSS. A foto real `assets/IMG_2751.jpg` foi otimizada para uso na hero em `assets/IMG_2751-hero.jpg`; a imagem original foi preservada.

As fotos cadastradas em `content.js` aparecem na galeria. Você pode substituir ou reorganizar os itens quando escolher outras imagens.

Arquivos principais: `content.js` (textos e imagens), `styles.css` (visual), `script.js` (componentes e interações) e `assets` (marca, fotos e grafismos).
